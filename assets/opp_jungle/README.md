# Open Pixel Project — Jungle tiles

CC0 / public domain. 35+ artists, DB32 palette, 32 px tiles.
Source: <https://opengameart.org/content/opp2017-jungle-and-temple-set>

Only `environment/tiles/` from the original download is vendored here. The
pack's own `readme guides IMPORTANT.txt` warns that the **guide and mockup
images may contain tiles that are not public domain**, so `guide_jungle.png`,
`guide_jungle_vines.png` and `mockups/` are deliberately left out. Do not add
them: this repository is public, and shipping them would redistribute art
whose rights are not established.

Sprites, backgrounds and objects from the pack are not vendored either -
nothing uses them yet. Add them the same way if that changes, tiles only.
